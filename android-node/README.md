# Android Vision Node
Kotlin + CameraX. MVP: gửi JPEG qua HTTPS/WebSocket; sau đó chuyển WebRTC/H.264.
Việc cần làm: foreground service đúng quyền, heartbeat, log nhiệt/pin/mạng.
Khởi tạo project bằng Android Studio (Empty Activity) ngay trong thư mục này.

Kế hoạch chuẩn bị đồng bộ dữ liệu với cloud và FamilyCare:
[Android Node integration](../docs/android-node-integration.md).
Hiện chưa có project Android hoặc kết nối thiết bị thật trong repository.
